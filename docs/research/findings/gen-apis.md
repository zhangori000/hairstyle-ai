# General-purpose image editing APIs for hair edits

_Research lane `gen-apis` from the 2026-10-20 sweep. Written by a research agent, then fact-checked by independent verifier agents; the verification section at the end records every correction. Numbers carry an as-of date and a source. Items marked unverified could not be confirmed from this sandbox (many vendor sites were blocked) and should be re-checked on the live page before you rely on them._

Long-form notes with every URL: [notes/gen-apis.md](../notes/gen-apis.md)

## Summary

As of 2026-10-20 the general-purpose editing-API field has turned over completely since 2025: Google's current line is Nano Banana 2.1 (gemini-nano-banana-2.1, GA Oct 6 2026, ~$0.034/1K image, up to 14 reference images, conversational multi-turn editing, SynthID+C2PA, paid tier not trained on), Nano Banana Pro ($0.134/1K-2K) and Nano Banana 2 Lite ($0.034); Imagen is shut down in the Gemini API and Imagen 3 edit/inpaint is discontinued on Vertex. OpenAI's line is GPT Image 2.5 Sunburst/Flare (Sep 8 2026; token-billed, roughly $0.013 medium to $0.21 max per 1024 image plus ~$0.008 per reference; real alpha-mask support, up to 16 input images; #1 on both Arena edit leaderboards) with gpt-image-1 shutting down Oct 23 2026 and 1.5/mini on Dec 1. Black Forest Labs shipped FLUX 3 Image (Oct 1-2 2026, $0.048/1K, 1-10 refs, bounding-box-confined edits, best measured outside-region pixel preservation) and FLUX 3 Image Klein open weights (Oct 15, $0.009/1K API, self-hostable, free under $5M revenue) — but BFL trains on direct-API inputs by default. ByteDance Seedream 5.0 Pro ($0.045, 10 refs, point/box/arrow spatial editing) is reported #1 on Artificial Analysis' identity-preserving-edit category but is slow (~90 s) and processes in SG/MY. Alibaba Qwen-Image 3.0 ($0.03) is the cheap hosted option; Qwen-Image-2.1 open weights are non-commercial. Ideogram 4.5 precise edit, Krea 3, xAI Grok Imagine Image 2.0 and Microsoft MAI-Image-2.6 are new contenders with little hair/identity evidence. Midjourney still has no API; Adobe Firefly Services is enterprise-only; Amazon Nova Canvas hit end-of-life Sep 30 2026. No benchmark is hairstyle-specific; evidence is Arena/AA leaderboards, GEditBench v2, hairstyle-transfer papers (HairPort, DPF) for metrics, and user reports: Nano Banana has the strongest hairstyle track record but drifts after ~4 chained edits; GPT Image follows instructions best but tends to re-render the whole face; FLUX is the most conservative editor. Recommended: Nano Banana 2.1 as primary, GPT Image 2.5 Sunburst as A/B, FLUX 3 Image/Klein (via fal/Replicate or self-hosted) for region-locked and most-private edits, Seedream 5.0 Pro for reference-hair transfer experiments, behind a provider-agnostic HairEditProvider interface; always re-edit from the original photo. Full notes at <scratchpad>/research/gen-apis.md. Caveat: direct page fetches were blocked in this sandbox; primary-source numbers come from search snippets of the official pages and should be re-checked on live pricing pages.

## Recommendations

- Adopt Nano Banana 2.1 (gemini-nano-banana-2.1) as the primary renderer: cheapest frontier editor (~$0.034/1K), multi-turn refinement, up to 14 reference images for hair-reference transfer, paid-tier no-training, SynthID+C2PA. Use Nano Banana Pro only as an opt-in 'higher likeness' mode (4x cost).
- Wire GPT Image 2.5 Sunburst as the second provider for A/B and for mask-constrained edits (real alpha-mask support, #1 on Arena edit boards), but expect whole-face re-rendering and stricter real-face refusals; run at medium/high quality, not max, and bill by measured usage tokens.
- Add FLUX 3 Image (via fal/Replicate, not BFL direct, because BFL trains on direct-API inputs by default) for region-locked hair edits using bounding boxes, and prototype FLUX 3 Image Klein self-hosted as the 'most private option that still works'.
- Design a provider-agnostic HairEditProvider interface (original photo, optional hair reference, optional mask/boxes, instruction, prior accepted output; returns image + provider metadata + safety outcome) so models can be swapped as leaderboards move; never chain edits — always re-edit from the original plus the accepted previous output as a reference to avoid identity drift.
- Build the refusal path in from day one: detect IMAGE_SAFETY / PROHIBITED_CONTENT (Google) and moderation_blocked (OpenAI), fall back to the other provider or FLUX, and never allow minors or celebrity photos.
- Pass photos inline/base64 and avoid persistent uploads (Gemini File API, fal CDN); set Interactions API store:false; send X-Fal-Store-IO: 0 on fal; prefer Replicate's 1-hour auto-delete when going through a marketplace; retire gpt-image-1/1.5/mini ids before their Oct 23 / Dec 1 2026 shutdowns.
- Run a bake-off before committing: 10-20 consented selfies x 10 hairstyles across Nano Banana 2.1, Pro, GPT Image 2.5 (with/without mask), FLUX 3 Image (with/without box), Seedream 5.0 Pro, Krea 3 and Ideogram 4.5; score ArcFace identity similarity, non-hair SSIM, DINOv3 hair similarity to the reference, latency, measured cost and refusal rate, plus a friends' blind A/B.
- Try Seedream 5.0 Pro specifically for the 'put this person's hair on me' feature (reported #1 identity-preserving edits, point/box annotations), accepting ~90 s latency and Singapore/Malaysia processing; treat Qwen-Image-2.1 head-swap LoRAs as research-only (non-commercial license).
- Exclude Midjourney (no API), Adobe Firefly (enterprise contract), Nova Canvas (EOL), Imagen (discontinued), and deprioritise Stability/Recraft/Runway for portrait identity work.
- Budget: at 150 edits/month for a friends group the primary stack costs under $15/month; set per-user daily caps and prefer batch endpoints for non-interactive bulk previews (half price on Google and OpenAI).
