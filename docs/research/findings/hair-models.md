# Specialized hair-transfer models, hair APIs and segmentation

_Research lane `hair-models` from the 2026-10-20 sweep. Written by a research agent, then fact-checked by independent verifier agents; the verification section at the end records every correction. Numbers carry an as-of date and a source. Items marked unverified could not be confirmed from this sandbox (many vendor sites were blocked) and should be re-checked on the live page before you rely on them._

Long-form notes with every URL: [notes/hair-models.md](../notes/hair-models.md)

## Summary

Specialized hair models vs general editors, for a solo dev building a private friends-only app. Runnable open hair-transfer models: HairFastGAN (NeurIPS 2024, MIT code, <1 s on V100, shape+colour reference transfer, 259 stars, dormant since 2024) is still the best open reference-transfer engine in 2026; diffusion successors Stable-Hair (Apache-2.0, trained on only ~6k/20k images), HairFusion (CC BY-NC-SA, 8.4 GB ckpt) and Stable-Hair v2 (multi-view turntables, no licence) are not clearly better on FID and are heavier; the 2026 papers that beat them (H-Adapter ECCV 2026, DPF ACM MM 2026) have no code; HairPort (SIGGRAPH 2026) is a 9-stage research pipeline (24 GB VRAM, Blender, minutes/pair, CC BY-NC-ND). Every StyleGAN-based model (HairFastGAN, Barbershop, HairCLIP/v2, StyleYourHair, HairMapper) depends on NVIDIA's non-commercial StyleGAN2 FFHQ weights and needs FFHQ-aligned 1024 crops (paste-back required). Fine for friends, a wall for monetization. General editors are the practical default: Nano Banana 2 (Gemini 3.1 Flash Image) ~$0.067/1K image, Gemini 3 Pro Image $0.134, FLUX.2 pro ~$0.045, Kontext pro $0.04, Qwen-Image-Edit 2511 (Apache-2.0, self-hostable, $0.03/MP on fal). Evidence on hair: Gemini convincing for most cuts but struggles with updos/textures unless made bald first, identity drift after chained edits, SynthID; H-Adapter reports FLUX.2 keeps the source hairstyle under pose gaps. Hair-specific APIs: YouCam launched an 11-endpoint Hair & Beard suite (June 2026) with hair-analysis endpoints and free playground key (unit price unverified, ~2 units/render); AILabTools Premium is the only cheap API with reference-image transfer ($0.025–0.072/call); fal/Replicate hair-change apps are $0.04 text-only. No vendor offers live photoreal hairstyle video; only Banuba/Snap 3D wigs (real-time, low realism) or anchor-frame edit + LivePortrait animation. Segmentation: MediaPipe HairSegmenter/SelfieMulticlass run in-browser (52–72 ms GPU on Pixel 6, Apache) and are the only commercially clean hair masks; all CelebAMask-HQ/LaPa parsers (BiSeNet, SegFormer face-parsing, SegFace) are research-only data; SAM 2 (Apache) and SAM 3 (848M, text concept prompts, SAM License) are server-side mask oracles. Recommended architecture: on-device MediaPipe mask for cropping/compositing/privacy + Gemini/FLUX/Qwen for ideation and refine loop with bald-first chaining + HairFastGAN self-hosted as the "copy this exact hair" specialist and second opinion + Hairmony taxonomy (18 attributes/74 labels) and HairCLIP's 44 style names as the typed HairDescription schema for prompts and the stylist hand-off.

## Recommendations

- Default engine: a general editor via API (Nano Banana 2 / Gemini 3 Pro Image, with FLUX.2 pro as A/B) for ideation, text-described styles and the refine loop; wrap every request in a two-step chain (bald → style) when the target is shorter/tighter than the current hair.
- Run on-device MediaPipe SelfieMulticlass/HairSegmenter in the browser before any upload: crop to the head, and after generation copy original pixels back outside a feathered hair+forehead mask so face/background stay bit-exact; add a runtime check for the iOS GPU class-order bug.
- Add HairFastGAN self-hosted (single GPU box or per-second Replicate/Modal) as the 'copy this exact hair from a photo' specialist and as a second opinion next to the general-editor result; accept FFHQ alignment + paste-back; note its NC StyleGAN2 weights only matter if you ever monetize.
- If privacy outranks convenience, self-host Qwen-Image-Edit 2511 (Apache-2.0) instead of calling Google/BFL; consider training a small reference-hair LoRA on it using consented pairs (the Cosplay LoRA proves feasibility).
- Define a typed HairDescription from the Hairmony taxonomy (18 attributes) plus HairCLIP's 44 style names; have a VLM fill it from the user's photo and from any reference photo; use the same object to build prompts, to drive refine commands ('shorter' = length enum step), and to generate the stylist hand-off text.
- Build the test set now: consented friend selfies (front/three-quarter/profile, two lighting conditions) plus synthetic faces, covering the documented failure classes (long→short, bald, braids/updos, pose gap, hats, harsh light, chained edits); score with identity similarity outside the hair mask and a VLM-as-judge on (source, reference, output) triplets.
- Skip HairPort, HairFusion, Barbershop, HairCLIPv2 and Stable-Hair v2 for production; read them for ideas only (bald converter, align-CA, multi-view). Revisit if H-Adapter or DPF release code.
- For video: ship 'live hair colour' (MediaPipe mask + recolor) and 'static style + animated preview' (edited frame → LivePortrait clip); do not promise live photoreal hairstyle swap.
- Try YouCam's free playground key for the hair-analysis endpoints (type/length/frizz/density) and AILab Premium for a cheap reference-transfer comparison, but keep vendor calls optional because their retention policies are unverified.
- Verify three numbers on official pages before budgeting: Google's current image pricing (and whether gemini-nano-banana-2.1 replaced 3.1 Flash Image), YouCam per-unit USD, and the MediaPipe hair model card licence.

## Findings (14)

- **[decision-critical]** _high confidence._ **HairFastGAN remains the best runnable open-source reference hairstyle transfer model in 2026: sub-second (0.52–0.78 s on V100), takes separate shape and colour reference photos, MIT code; newer diffusion models are not clearly better on FID and the 2026 SOTA papers have no code.**  
  Stable-Hair v2's table: Barbershop 46.1, HairCLIPv2 37.3, HairFastGAN 36.4, Stable-Hair 36.1, v2 35.1 FID. HairPort's table shows HairFastGAN 37.1 vs Stable-Hair 64.9 and admits HairFastGAN beats it on FID. H-Adapter's user study prefers itself over HairFastGAN only 55.3% (vs 81.1% over HairCLIPv2). H-Adapter and DPF have no public code; HairFusion is CC BY-NC-SA with an 8.4 GB checkpoint; HairPort needs 24 GB VRAM, Blender, minutes per pair. Repo: 259 stars, 8 commits, last dated update 2024-09-25, 12 open issues.

- **[decision-critical]** _high confidence._ **All StyleGAN-based hair models (HairFastGAN, Barbershop, HairCLIP, HairCLIPv2, Style-Your-Hair, HairMapper) depend on NVIDIA StyleGAN2 FFHQ pretrained weights that are licensed non-commercial, and they require FFHQ-aligned 1024x1024 face crops (output is the crop, not the original photo).**  
  HairFastGAN's hair_swap.py defaults to pretrained_models/StyleGAN/ffhq.pt (size 1024); HairCLIP uses rosinality's FFHQ StyleGAN2 1024; HairCLIPv2 requires FFHQ StyleGAN 1024 + HairMapper bald proxy (explicitly non-commercial, Windows-only). NVIDIA NGC lists StyleGAN2 FFHQ models as 'ready for non-commercial use'; the Nvidia Source Code License-NC limits the Work and derivatives to research/evaluation. Fine for a private friends app; blocks monetization unless weights are replaced.
