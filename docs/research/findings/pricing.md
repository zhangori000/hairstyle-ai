# Unit economics and pricing

_Research lane `pricing` from the 2026-10-20 sweep. Written by a research agent, then fact-checked by independent verifier agents; the verification section at the end records every correction. Numbers carry an as-of date and a source. Items marked unverified could not be confirmed from this sandbox (many vendor sites were blocked) and should be re-checked on the live page before you rely on them._

Long-form notes with every URL: [notes/pricing.md](../notes/pricing.md)

## Summary

Cost is dominated by the image-edit model: 36 renders/user/month at $0.034-0.134 each sets the bill; face analysis is under 3% of session cost on any LLM. Verified list prices (2026-10-20, primary sources where reachable): Google image models on Vertex are the cheapest high-quality edit tier (Nano Banana 2.1 $0.034/1K image, Gemini 3.1 Flash-Lite Image $0.034, Gemini 2.5 Flash Image $0.039, Gemini 3.1 Flash Image/NB2 $0.067, Gemini 3 Pro Image $0.134; 2K/4K cost 1.5-3x). FLUX.1 Kontext pro/max are $0.04/$0.08 (LiteLLM BFL entries, Azure mirror). OpenAI gpt-image-1 is $0.011/$0.042/$0.167 (low/med/high, 1024², snapshot of OpenAI docs 2026-10-04); gpt-image-2 ~$0.007/$0.063/$0.253 and gpt-image-2.5 ~$0.008-0.30 per ComfyUI badges (secondary). Vision analysis of one 1024² photo + 1,500 prompt + 800 output tokens: Claude Haiku 5.5 $0.0007 (1,369 image tokens via 28-px patches), Gemini 2.5 Flash $0.0028, gpt-5-mini $0.0024, Sonnet 5.5 $0.0137, Opus 5.5 $0.0275, Fable 5.1 $0.069. Video (Veo 3.1 Lite/Fast $0.15-0.50 per 5 s; Kling/Wan/Luma $0.25-0.56 via ComfyUI badges) is only for exported clips, not live try-on. Scenarios (3 sessions × 12 renders + analysis per user/month): mid stack (Sonnet 5.5 + Nano Banana/Kontext pro) ≈ $1.45/user → $14.5 (10 friends), $145 (100), $1,445 (1,000); cheapest sane $0.40-1.23/user; premium (Opus + NB Pro/gpt-image high) $4.9-6.1/user → $4.9-6.1k at 1,000 users. Hosting is noise: Cloudflare Workers Free + R2 (10 GB free, zero egress) or Vercel Hobby (non-commercial, hard caps) at $0; at 1,000 users $5-45/month; Supabase Free covers auth (50k MAU) and Firebase Auth is free to 50k MAU. Self-hosting FLUX Kontext dev (non-commercial license, verified) costs ~$0.0075-0.024 per edit at estimated 8-20 s/edit on $1.09-5.49/hr GPUs (Modal H100 $3.95, RunPod secure A100 $1.59, Replicate H100 $5.49; secondary snapshots) and only beats the $0.04 tier above ~1,000 users. The real scaling walls are money caps, not RPM: Anthropic Start tier $500/month cap (1,000 RPM, 2M ITPM), Gemini Tier 1 $250 billing cap and $10 per rolling 10 min, OpenAI Tier-1 ~$100/month. Decision-critical privacy fact: Gemini API free tier terms let Google use submitted content and generated responses to improve products with human review (verified via mirror of the terms), so face photos must only go through a billed key or Vertex; Anthropic states images are not stored beyond the request and not used for training. Limitation: WebSearch was exhausted and the proxy blocked all vendor pricing sites except Anthropic, Google Cloud, GitHub, PyPI and npm; BFL/fal/Replicate/OpenAI/Modal/RunPod/Vercel/hair-API prices are from dated secondary sources and are flagged.

## Recommendations

- Treat the edit model as the only cost lever that matters: prototype two tiers side by side (Gemini 3.1 Flash Image at $0.067 and FLUX.1 Kontext pro at $0.04, with Nano Banana 2.1 at $0.034 as the cheap fallback) and keep gpt-image-2 low (~$0.007) in the harness purely as a cost floor to measure identity drift.
- Use Claude Haiku 5.5 ($0.0007/photo) or Gemini 2.5 Flash ($0.003) for the structured face/hair analysis; move to Sonnet 5.5 only if JSON quality demands it, because analysis is under 3% of session cost.
- Attach billing to the Google/Gemini key (or use Vertex AI) before the first face photo is sent; the free tier's terms allow Google to use content for product improvement with human review. Keep Anthropic (ephemeral images, no training) as the default analyst if privacy is the top priority.
- Budget $1.5-2.5 per active user per month on the mid stack at list prices ($15-25/month for 10 friends); set hard spend limits at each provider (Anthropic console limit, Gemini Tier-1 cap, OpenAI project budget) and plan for Anthropic Build tier and Gemini Tier 2 before ~300-500 users on any $0.067+ edit model.
- Host on free tiers for the friends phase: Cloudflare Workers Free + R2 (zero egress) or Vercel Hobby (non-commercial is acceptable for a friends app), Supabase Free for auth/DB; expect $5-45/month total hosting even at 1,000 users.
- Do not self-host GPUs before ~1,000 users; when you do, benchmark seconds-per-edit on Modal (scale-to-zero, $30/month credit) and compare to the $0.04 API tier, and remember FLUX.1 Kontext dev is non-commercial while Qwen-Image-Edit is (reportedly) Apache-2.0.
- Offer video only as an exported 5-second turntable using Veo 3.1 Lite/Fast ($0.15-0.50) or Wan 2.6 720p ($0.50); design live camera try-on as a client-side segmentation/overlay feature, not a generative-video call.
- Re-verify on the vendor pages the numbers flagged unverified in the notes (gpt-image-2/2.5 per-image tiers, BFL list prices, fal/Replicate hosted Kontext dev and Qwen-Image-Edit, Vercel Blob, Clerk/Auth0, Runway credits) before committing to a budget; the primary-verified set (Anthropic, Google, Cloudflare, Supabase, Fly.io) is safe to use as-is.
