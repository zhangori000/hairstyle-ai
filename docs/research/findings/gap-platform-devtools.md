## Summary

Gap-fill for platform and tooling facts (2026-10-20; 15/15 searches used, vendor hosts and Wayback blocked, so facts come from Apple pages, developer.android.com, vendors' own docs/website source repos on GitHub, npm registry, and search snippets). Key corrections: Safari 27.0 (Sep 14, 2026) stopped auto-converting HEIC to JPEG on file input, so the web capture path must handle HEIC (createImageBitmap/img decode HEIC on Safari per field reports; capture=user file type undocumented); getUserMedia works in installed web apps but iOS 26.x has an unfixed-in-thread ~90-degree camera rotation bug in home-screen mode; WebGPU is default-on in Safari 26+ (with an iOS 26 importExternalTexture orientation bug) but MediaPipe tasks-vision has no WebGPU delegate. Current iOS is 27.0.1 with 27.2 RC. Vercel: Hobby is personal/non-commercial per official page snippet (friends-app case not explicitly addressed), Blob storage $0.023/GB-month, body limit and Workflow pricing unverifiable. Cloudflare Workflows, Inngest, Trigger.dev limits, Langfuse, Expo usage prices, Apple $99 fee and TestFlight limits are confirmed from primary/source-repo pages; Trigger.dev prices, Expo plan prices, Braintrust and Helicone paid tiers remain secondary. The Aug 25, 2026 Android Developers Blog NCII post exists (primary read) and is guidance: reviewer test accounts must reach all AI features, keep documentation of safety-prompt tests, special attention to nudify/deepfake/explicit edits. Apple 5.1.2(i) third-party-AI consent wording confirmed, page last updated Oct 16, 2026. Libraries: better-auth 1.7.12 with passkeys as separate @better-auth/passkey; XState 5.33.3 stable, 6.0.0-alpha.70; Zod 4.6.7; AI SDK ai 7.0.146, and generateImage now takes prompt.images/prompt.mask with supportsFileInputs/supportsMaskInputs flags (Google: images yes, masks no; OpenAI: images up to 16 + mask; BFL flux-3-image: 10 refs, no mask; flux-pro-1.0-fill: mask).

## Corrections to the first sweep

- **Before:** AI SDK generateImage documents no input-image parameter; image editing must go through generateText files (architecture lane).  
  **Now:** Current vercel/ai docs document generateImage with prompt: { text, images, mask } and per-model capability flags supportsFileInputs / supportsMaskInputs. Google models accept images but not masks; OpenAI gpt-image-* accept up to 16 images plus a transparent-area mask; BFL flux-3-image/klein accept up to 10 reference images and reject masks; flux-pro-1.0-fill accepts a mask. Version alignment with ai@7.0.146 still needs a changelog check.  
  Sources: <https://raw.githubusercontent.com/vercel/ai/main/content/docs/03-ai-sdk-core/35-image-generation.mdx>, <https://raw.githubusercontent.com/vercel/ai/main/content/providers/01-ai-sdk-providers/15-google.mdx>, <https://raw.githubusercontent.com/vercel/ai/main/content/providers/01-ai-sdk-providers/03-openai.mdx>, <https://raw.githubusercontent.com/vercel/ai/main/content/providers/01-ai-sdk-providers/12-black-forest-labs.mdx>
